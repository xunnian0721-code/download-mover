# 下载整理助手 (Download Mover)

一个轻量的 Windows 小工具：列出下载文件夹里最新的文件，可以手动多选一起移到指定文件夹；也可以开启「自动存放」，之后每个新下载完成的文件都会自动移过去。移错了还能一键撤销。

- 不用安装任何东西，只用 Windows 自带的 PowerShell 5.1 + WinForms
- 常驻托盘后台运行，内存约 10~35 MB；靠系统文件变动通知发现新文件，空闲时 CPU 基本为 0
- 支持 Chrome / Edge / Firefox 等浏览器：会等下载真正完成（跳过 `.crdownload`、`.part` 等临时文件）再移动
- 目标文件夹有同名文件时自动改名为 `文件名 (1)`，不会覆盖

## 功能

| 功能 | 说明 |
| --- | --- |
| 手动整理 | 列出最新 50 个下载，勾选（可多选）后点「移动勾选的文件」 |
| 自动存放 | 打开开关后，新下载完成的文件自动移到目标文件夹，右下角弹提示 |
| 已完成 / 撤销 | 右侧列表记录每次移动（标明手动/自动），勾选后可撤销，文件移回原下载文件夹 |
| 托盘运行 | 关窗口只是缩到托盘；右键托盘图标可开关自动存放、设置开机自启、退出 |

## 使用

1. 下载本仓库（右上角 **Code → Download ZIP**），解压到任意文件夹
2. 双击 `启动下载整理.vbs`
3. 点「目标文件夹」右边的「更改」选好存放位置，之后按需手动移动或打开「自动存放」

想开机自动启动：右键托盘图标 → 勾选「开机自动启动」。

更详细的说明见 [使用说明.txt](使用说明.txt)。

## 文件

| 文件 | 作用 |
| --- | --- |
| `启动下载整理.vbs` | 启动器，隐藏控制台窗口运行脚本 |
| `DownloadMover.ps1` | 程序本体 |
| `config.json` | 个人设置，首次运行后自动生成 |
| `history.json` | 已完成记录（最近 200 条），自动生成 |

## 系统要求

Windows 10 / 11（自带 PowerShell 5.1 即可）。
